## 文档分层

| 层 | 文件 | 性质 |
|---|---|---|
| 入口 | `AGENTS.md`（仓库根） | 冷启动手册：铁律 / 关键基准 / 发布流程 / 已知坑。**保持短** |
| 地图 | `docs/README.md` | 本文 |
| **活文档** | `docs/交接-当前状态.md` | 线上实况 + 欠什么 + 发布记录 |
| **实施记录** | `docs/记录-*.md`（作业域 / 员工填报 / 日期计划） | **每个功能区一份**：口径、踩坑、实测数据。改哪块读哪份 |
| 设计/方案 | `docs/技术方案.md`、`docs/产品设计-系统逻辑全览.md`、`docs/结算主流程设计-v3.md` | 架构、数据模型、业务逻辑；v3 是 2026-09-08 客户确认稿 |
| 全流程 | `docs/任务域-全流程.md` | 任务域端到端（定义→分配→执行→汇总 + 验收清单） |
| 手册 | `docs/MCP对接手册.md` | 对外可复用（协议 / OAuth / 工具设计规范） |
| 清单 | `docs/发布清单-作业域.md`、`docs/测试用例-任务域.md` | 发布前核对 / 用例目录 |
| 跟踪 | `docs/问题单-已核实缺陷.md` | 已核实未修的缺陷 |
