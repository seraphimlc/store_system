# 巡店数据结算系统 — 页面交互清单（UI/交互共同输入）

- 日期：2026-09-04
- 配套：设计文档 `2026-09-04-store-settlement-web-design.md`（spec v0.3）
- 定位：本清单是页面结构/表格列/操作/点击行为的**共同输入**——给外部 demo 方按它出稿，也作为内部开发（htmx 服务端渲染）的实现依据
- 技术：Jinja2 + htmx + Alpine.js，服务端渲染，全站登录后使用；默认中文界面；金额单位円

---

## 0. 全局约定

- **导航栏**：Logo/系统名 | 仪表盘 | 巡店文件 | 清洗任务 |（阶段二）对账 | 右侧当前用户 + 退出
- **期次语境**：业务以"期次(月)"为单位。入口在"清洗任务"；进入某个 run 后各统计页都挂在 `/runs/{id}` 下，页面顶部显示 run 标签（如"2026-07"）+ 规则快照摘要 + 可一键返回 /runs
- **表格通用行为**：表头加粗、冻结首行、斑马纹；服务端分页（每页 100，页脚 上一页/页码/下一页 + 总数）；关键列可排序（默认按注释指定）；全量数据走"导出"
- **状态色**：成功/一致=绿，警告=琥珀，错误/不一致=红，信息=蓝
- **异步任务**：清洗任务为后台执行；页面用 htmx 轮询（每 2s）刷新状态徽标，不整页跳转
- **空/错态**：空表格显示"暂无数据"；错误以红底提示条 + 明细列表呈现，不吞异常

## 1. /login 登录

- 表单：用户名、密码、登录按钮
- 校验失败：红字"用户名或密码错误"；连续失败 5 次后锁定 60s（倒计时提示）
- 成功 → 跳 /（仪表盘）
- 无注册入口（账号由管理员预置，v1 单角色 admin）

## 2. / 仪表盘

- 内容三块：
  1. 最近上传文件（最近 5 条：文件名/月份/状态/时间）
  2. 最近清洗任务（最近 5 条：标签/状态/完成时间/总点数摘要）
  3. 快捷操作按钮：`上传巡店文件`（→/files）、`新建清洗任务`（→/runs 新建表单）
- 均为纯展示 + 跳转，无复杂交互

## 3. /files 巡店文件

**3.1 上传区（页首）**
- 拖拽或点击选择，支持多文件、仅 .xlsx、单文件上限 50MB
- 上传中：每个文件显示进度条；上传完自动触发解析
- 解析完成逐文件出结果行（见 3.2），失败文件红字列出 errors（缺列/时间无法解析/值域异常等，含原因）

**3.2 文件列表（表格，默认按上传时间倒序）**

| 列 | 说明 | 排序 |
|---|---|---|
| 文件名 | 原名 | 可 |
| 月份标签 month_label | 导入时按文件名/日期范围给出建议，可下拉修改（2026-04…2026-08 及"未标记"）| 可 |
| 格式 | wide50/flat9/其他（探测结果）| — |
| 数据行数 | parsed_rows / total_rows | 可 |
| 状态 | 徽标：已解析/失败(+错误数)/上传中 | — |
| 警告 | 琥珀小字或图标，悬停/点击展开 warnings（忽略的 sheet、可见列无 NO 等）| — |
| 上传人/时间 | — | 可 |
| 操作 | `重传`（同 sha256 会提示已存在）、`删除`（仅未参与任何 run 时允许，二次确认）| — |

**3.3 交互**
- 点击警告图标 → 弹出层展示该文件 warnings/errors 完整数组
- 月份标签就地编辑（下拉即时保存）
- 删除：确认框"删除后将移除该文件全部原始记录（已建 run 引用时禁止删除）"

## 4. /runs 清洗任务

**4.1 新建任务表单**
- `期次标签`：文本框，默认按所选文件自动建议（如"2026-07"）
- `文件选择`：两种方式
  - 按月份：下拉选 month_label → 自动勾选该期所有"已解析"文件
  - 手动：文件多选列表（含月份列）自由勾选
  - 显示将合并的总行数（sum parsed_rows）
- `高级参数（默认折叠）`：分界日（默认 2026-07-09，日期输入）；`店名判重前 trim`开关（默认开；附录 B 差异族 B-1 说明文字内联提示）
- 提交 → 建 run（status=running），跳转运行历史该行并进入轮询

**4.2 运行历史（表格，按创建时间倒序）**

| 列 | 说明 |
|---|---|
| 标签 label | 点击 → /runs/{id}/overview |
| 状态 | pending/running(动画)/done/failed |
| 输入文件数 | summary 中可见 |
| 最终有效/总点数 | done 后显示；failed 显示错误数 |
| warnings 摘要 | 平局组数、全空键行数等（琥珀图标，点击展开）|
| 规则版本 | rule_version |
| 创建人/时间/耗时 | — |
| 操作 | done：`查看总览`、`导出`；running：`取消`；failed：`重试`（同参数重建）|

**4.3 轮询**：running 行状态徽标每 2s 刷新；done 后自动显示结果摘要并可用。

## 5. /runs/{id}/overview 月度总览

- 顶部：run 标签、规则快照摘要（分界日/trim 开关/rule_version/运行时间/文件清单，可折叠）
- 九宫格卡片（需求书 §4）：
  `原始记录`、`可见非空`、`可见空白`、`A列重复`、`B列重复`、`最终有效`、`1点`、`2点`、`总点数`
- 附加审计行：`全员精算金额`、`未识别行数`（amber，含"未识别"提示）
- 每张卡片可点击 → 对应明细（有效 → 无独立页，指向 duplicates？否——映射如下）：
  - 原始/可见非空 → 无明细页（太大），提示"请用导出"
  - 可见空白 → /runs/{id}/export 内 Visible空白 sheet（或占位提示）
  - A列重复/B列重复/最终有效 → 跳 /runs/{id}/duplicates（带 bucket 过滤参数）与 /runs/{id}/persons 列表
- 不变量自检徽标：`✓ 核对关系通过`（绿）或 `✗ 不通过`（红，数据不应出现——显示错误并引导联系管理员）

## 6. /runs/{id}/persons 人员成绩

- 表格列（需求书 §4.2，点击行 → 人员明细）：

| 列 | 说明 |
|---|---|
| 姓名（persons.display_name）| |
| 人员编号 | 小字副列 |
| 原始提交 | |
| Visible空白 | |
| 最终有效 | |
| 重复（dup_by_id+dup_by_name 合计）| 点击展开两类细分 |
| 1点 / 2点 / 总点数 | |
| 精算金额 | 右侧加粗 |
| 操作 | `明细`（→ /runs/{id}/persons/{code}）|

- 默认按总点数降序；顶部小计行（合计列）
- 底部含"未识别（submitter_code 为空）"一行：计数展示、标琥珀，不可点击明细（仅展示）
- 每列数值可点击钻取：原始提交 → 该人全部记录数（导出含）；最终有效 → 明细页"有效店铺"；等

## 7. /runs/{id}/persons/{code} 人员明细

页面结构（Tab 或分区）：
1. **Tab 有效店铺**：表格 = Store ID / 店名 / Modified(日本日期+时间) / 1点或2点徽标 / 来源文件
2. **Tab 重复店铺**：表格 = Store ID / 店名 / bucket(A列/B列) / 重复原因 / dup_of(最早保留者：提交人+时间+文件) / 原行来源；dup_of 非 final 时显示其去向链（一次展开）
3. **Tab Visible空白**：表格 = Store ID / 店名 / Modified / 来源文件
4. **Tab 每日成绩**：表格 = 日本日期 / 最终有效店数 / 1点 / 2点 / 当日总点数（对应 daily_system_points；为阶段二自报对账的"系统侧"）
- 顶部：该人员姓名+编号+汇总卡（最终有效/总点数/精算金额）
- 每个 Tab 可独立导出当前 Tab 数据（csv 或并入大导出）

## 8. /runs/{id}/duplicates 重复明细

- 过滤条：bucket 全部/A列重复/B列重复；关键字（Store ID/店名/提交人编号）
- 表格列：Store ID、店名、bucket、原因（"同 Store ID 已有更早记录" / "同店名已有更早记录"）、dup_of 引用（提交人/时间/文件/行号）、dup_earliest 快照、原文件+Excel行号
- dup_of 非 final：原因单元格后跟琥珀链接"该保留者本身为 B 列重复 →"，点击展开其去向（链式一次）
- 分页 + 全量导出（sheet `全部重复`）

## 9. /runs/{id}/export 导出

- 单一操作页：按钮 `生成并下载结算 Excel`
- 说明文字列出工作簿 8 个 sheet 清单（月度总览/人员汇总/个人精算/每日系统成绩/最终有效/全部重复/Visible空白/个人明细）
- 可选：勾选是否包含 `个人明细` sheet（大数据时体积大）
- 下载完成后提示；同一 run 可重复导出（结果由 DB 现算，不缓存）

## 10. 阶段二：对账页面（详细设计见 2026-09-04-reconciliation-design.md）

- `/reconcile` 对账任务列表：新建任务（类型：每日自报 / 闫总月度参考；选 run + 账单文件）、任务历史（summary/状态）
- `/reconcile/{id}` 差异主页面：状态计数卡；粒度切换 日（默认仅非一致）/周/月；表格列 日期·人员·系统点数·自报点数·差额·状态·确认·备注；行点击抽屉展示系统当日明细与账单原始行；操作 确认/备注/本周全确认/导出
- `/reconcile/{id}/unresolved` 自报姓名→编号未匹配名单（管理员建别名或手工指定后重导该行）
- 差异 Excel：见对账设计 §6（默认只含差异；全量另存归档）
- 预留导航菜单项 `/reconcile`、`/self-reports` 在阶段二点亮，此前灰置

## 附：通用错误与边界表现

| 场景 | 表现 |
|---|---|
| run 清洗失败（不变量不满足/中断）| 运行历史该行红色 failed；点击展开错误；可重试 |
| 文件解析失败 | /files 列表红字 errors 数组；不进任何 run |
| 上传同名 sha256 | 提示"该文件已存在(同名/同内容)"，不重复入库 |
| 删除被 run 引用的文件 | 禁止 + 提示引用它的 run |
| 未登录访问 | 302 到 /login，登录后回跳原页面 |
| 大表 | 一律分页（100/页）+ 导出全量，页面不做无限滚动 |
