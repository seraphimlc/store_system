# Google Maps Platform API Key 申请流程（员工打卡功能用）

> 用途：员工 H5 打卡页需要「嵌入式谷歌地图 + 店铺查询接口」。
> 本文分两部分：**中文要点（内部用）** + **日本語手順書（直接转给客户照着做）**。
> 事实核对时间：2026-09-27；计价口径为 Google 官方 2025-03-01 起的新方案。

---

## 一、内部要点（中文）

### 1. 谁申请、谁持有
- **客户自己申请、自己持有**（Google Cloud 项目 + 结算账号都是客户的），我们只是把 key 配到服务器环境变量里，**不写进代码库**。
- 建议客户用**公司 Google Workspace 管理员账号**建项目，不要用某个员工个人账号（人走了 key 就没人能管）。
- 计费走客户的信用卡/结算账号，我们这边不承担费用。

### 2. 需要客户开通的 API（3 个）
| API | 用途 | 备注 |
|---|---|---|
| **Maps JavaScript API** | H5 里嵌地图、落 pin、拖拽纠偏 | 必开 |
| **Places API (New)** | 店名/地址搜索框（Autocomplete + Text Search） | 必开，**必须是新版 (New)**，旧版已是 legacy |
| Geocoding API | 坐标⇄地址互转 | 可选，用于回显地址 |

### 3. 免费额度与费用（2025-03-01 后）
- 旧的「每月 $200 通用抵扣」**已取消**，改为 **每个 SKU 每月固定免费次数**：
  **Essentials 10,000 次 / Pro 5,000 次 / Enterprise 1,000 次**。
- 与本功能相关的 SKU：
  | SKU | 档位 | 每月免费 | 超出单价 |
  |---|---|---|---|
  | Dynamic Maps（地图加载） | Essentials | 10,000 | $7.00 / 1,000 |
  | Autocomplete Requests（搜索联想） | Essentials | 10,000 | $2.83 / 1,000 |
  | Autocomplete Session Usage | Essentials | **无限制·免费** | — |
  | Place Details Essentials（取店名/地址） | Essentials | 10,000 | $5.00 / 1,000 |
  | Place Details / Text Search **IDs Only** | Essentials | **无限制·免费** | — |
- 日本另加消费税。参考：[官方计价页](https://mapsplatform.google.com/pricing/)、[2025-03 变更说明](https://developers.google.com/maps/billing-and-pricing/march-2025)。

### 4. 我方用量估算（34 人 × 15 家/日 × 22 日 ≈ 11,200 次/月）
| 方案 | 说明 | 估算费用 |
|---|---|---|
| A：全部走谷歌 | 每次打卡都调地图 + 联想 + 详情 | ≈ **$100/月**（约 ¥15,000） |
| **B：本地优先（推荐）** | 搜索先查系统内 4.2 万条店铺主档 + 自己的打卡点位；查不到才走谷歌 | ≈ **$10/月**，多数月落在免费额度内 |

→ 设计上我会做成 **B**：本地优先 + 谷歌兜底，并且**谷歌额度用尽时自动回落本地检索**（不会因为超额就卡住员工）。

### 5. 要客户回给我们的东西
1. 浏览器用 API Key（**只需这一把**——地图与搜索都在浏览器直连谷歌，我们不做服务端谷歌调用）
2. 项目 ID + 已开通的 API 清单 + 设的配额上限（截图即可）
3. 结算账号负责人（谁付费）
4. 交付渠道：**不要微信/邮件明文**，用密码管理器或一次性链接

### 6. key 没到位之前怎么办
代码按「有 key」写，用环境变量 `VISIT_GOOGLE_MAPS_KEY` 控开关：
- **无 key**：地图用免费 OpenStreetMap 显示定位点，搜索用系统内店铺主档 + 打卡点位簿 → 功能不中断；
- **有 key**：只改 env + 重启，自动切到谷歌地图 + Places 搜索，**不需要改代码、不需要重新发布**。
- 切换后需要补一轮验收：地图能加载、搜索能出候选、定位点能拖拽、超额回落正常。

# Google Maps Platform APIキー取得手順

対象：従業員チェックイン（H5）機能で使用する地図・店舗検索用のAPIキー
所要時間：約20〜30分（お支払い情報の登録を含む）
ご準備いただくもの：会社のGoogleアカウント（Google Workspace管理者推奨）、クレジットカード

## 0. 事前にご確認いただきたいこと

- **アカウントは個人のGmailではなく、会社のGoogle Workspace管理者アカウントで作業してください。** 担当者様の退職などでキーの管理ができなくなることを防ぐためです。
- プロジェクト・お支払いは**貴社名義**で作成いただきます（当社は費用を負担いたしません）。
- お支払いはクレジットカード（Visa / Mastercard / JCB / American Express）が基本です。法人向けの請求書払いはGoogle Cloudの条件を満たす場合のみ申請可能ですので、ご希望の場合はGoogle Cloudの営業担当へご相談ください。
- 日本からのご利用の場合、利用料金に**消費税**が加算されます。

## 1. Google Cloud プロジェクトの作成

1. https://console.cloud.google.com/ にアクセスし、上記アカウントでログインします。
2. 画面上部のプロジェクト選択 → 「新しいプロジェクト」。
3. プロジェクト名を入力します（例：`visit-settle-maps`）。組織をお持ちの場合は組織配下に作成してください。
4. 作成後、そのプロジェクトが選択された状態にします（以降の作業はすべてこのプロジェクト内で行います）。

## 2. お支払い情報（請求先アカウント）の設定

1. 左メニュー「お支払い」→「請求先アカウントを作成」。
2. 国：日本 / 通貨：JPY を選択し、クレジットカード情報を登録します。
3. 作成した請求先アカウントを、手順1のプロジェクトにリンクします。

> ご注意：2025年3月1日以降、従来の「毎月200米ドル分の無料クレジット」は廃止され、**SKU（機能）ごとの毎月の無料回数**に変更されました（手順6参照）。また、新規のGoogle Cloudアカウントには90日間・300米ドル分の無料トライアル枠が付与される場合があります（対象条件はご契約時にご確認ください）。

## 3. APIの有効化（3つ）

「APIとサービス」→「ライブラリ」で以下を検索し、それぞれ**「有効にする」**を押します。

| API名 | 用途 |
|---|---|
| **Maps JavaScript API** | Webページへの地図埋め込み（必須） |
| **Places API (New)** | 店舗名・住所の検索／入力補完（必須） |
| Geocoding API | 住所と座標の相互変換（任意） |

> **重要：** 店舗検索は必ず **「Places API (New)」** を有効化してください。「Places API」（旧版）はレガシー扱いとなっており、新機能が使えません。

## 4. APIキーの作成（ブラウザ用・1本）

1. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」。
2. 作成されたキーの「編集」を開き、**必ず次の2つの制限を設定**してください。
   - **アプリケーションの制限**：「ウェブサイト」を選択し、以下を追加
     - `https://store.visitworld.me/*`
     - `http://127.0.0.1:8000/*`（当社の開発・検証用。不要であれば削除いただいて構いません）
   - **APIの制限**：「キーを制限」→ `Maps JavaScript API` と `Places API (New)` のみにチェック

> ブラウザ用のキーは利用者の画面から見える位置に埋め込まれます。**リファラー制限＋API制限＋クォータ上限（手順5）の3点セット**で保護するのがGoogleの推奨構成です。
> （さらに厳密にしたい場合は、Maps JavaScript APIの「URL署名」または「App Check」をご利用いただけます。ご希望があれば当社で設定方法をご案内します。）

## 5. 使用量の上限とアラート（費用の青天井を防ぐため必須）

1. 「Google Maps Platform」→「クォータ」で、APIごとに**1日あたりの上限**を設定します。推奨値：
   - Dynamic Maps：2,000 / 日
   - Autocomplete Requests：2,000 / 日
   - Place Details：1,000 / 日
   （当システムは上限に達すると自動的にシステム内検索へ切り替わるため、上限到達でも業務は止まりません）
2. 「お支払い」→「予算とアラート」で、例として**月額 10,000円**のアラートを設定します。

## 6. 無料枠と料金（2025年3月1日以降）

無料枠は**SKUごと・毎月リセット**です：**Essentials 10,000回 / Pro 5,000回 / Enterprise 1,000回**。

本機能で使用する主なSKU：

| SKU | 分類 | 毎月の無料回数 | 超過時の単価 |
|---|---|---|---|
| Dynamic Maps（地図の読み込み） | Essentials | 10,000 | $7.00 / 1,000回 |
| Autocomplete Requests（入力補完） | Essentials | 10,000 | $2.83 / 1,000回 |
| Autocomplete Session Usage | Essentials | 無制限・無料 | — |
| Place Details Essentials（店名・住所の取得） | Essentials | 10,000 | $5.00 / 1,000回 |
| Place Details / Text Search（IDs Only） | Essentials | 無制限・無料 | — |

**当システムでの概算**（従業員34名 × 1日15件 × 月22日 ≒ 11,200件/月の場合）：

- すべての操作でGoogleを呼び出す構成：月額 約100米ドル（約15,000円）
- **当社推奨構成（システム内の店舗データを優先し、必要な場合のみGoogleを利用）**：月額 約10米ドル程度、多くの月は無料枠内に収まる見込み

## 7. 当社へご連携いただく情報

1. 手順4で作成した**APIキー**
2. **プロジェクトID**、有効化したAPIの一覧、設定したクォータ上限（画面のスクリーンショットで結構です）
3. 請求先アカウントの管理者（どなたがお支払いを担当されるか）

> **キーの受け渡しは安全な方法でお願いいたします。** チャットやメールへの平文記載は避け、パスワード管理ツールの共有機能や有効期限付きの共有リンクをご利用ください。当社側ではサーバーの環境変数にのみ設定し、ソースコードやリポジトリには保存いたしません。

## 8. よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 地図に「For development purposes only」と表示される | 請求先アカウントが未設定／プロジェクトにリンクされていない（手順2） |
| 検索しても候補が出ない | Places API (New) が未有効、またはキーのAPI制限に含まれていない（手順3・4） |
| `RefererNotAllowedMapError` が出る | リファラー制限にドメインの登録漏れ。`https://store.visitworld.me/*` を正確に登録（`www` の有無、末尾の `/*` にご注意） |
| 特定のAPIだけ `REQUEST_DENIED` | そのAPIがプロジェクトで未有効化 |
| キーが漏えいした可能性がある | Cloud Consoleでキーを削除し再発行 → 新しいキーを当社へご連携ください（当社側で環境変数を差し替えて再起動します） |

## 9. キー取得までの暫定運用について

APIキーのご準備が完了するまでの間も、**機能を止めずに運用を開始できます。**
- 地図表示：OpenStreetMap（無料）で現在地を表示
- 店舗検索：当システム内の店舗マスタ（約4.2万件）＋過去のチェックイン履歴から検索

APIキーをご連携いただいた時点で、当社側の設定変更のみで**Googleマップ＋Places検索へ切り替え**いたします（アプリの再開発は不要です）。
