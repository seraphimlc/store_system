## 四、确认的现象（**不是 bug，是要改的规则**）

- **点 B**：派工没有"今天"的概念，派了就长期挂在队员名下 → 按 §8-1 改成「每天派 + 未完成自动延续」
- **点 C**：**确认后队员仍能改**（改成 20% → 状态被打回 `待确认`）→ 按 §8-3 加「当天已确认 → 队员不可改」
  （同值重提交已保护，不会误打回 ✓）
- **点 D**：**管理员随时能改**（未确认的也能改）→ 按 §8-4 加前置「必须该天已被队长确认」
- **点数与进度分成两页两次提交** → 按 §8-7 合并
