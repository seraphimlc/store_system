## 目标与层级

先在23区验证真实边界与形状，再扩展地区；解决为补面积/低负载形成的长臂、深凹、狭颈和狭长片区。019/031/066/067及051是问题样例，先记录版本/source_id/几何指纹，用空间和成员对应比较，不依赖编号稳定。

| 层级 | 方法 | 用途 |
|---|---|---|
| 自然地块 | 主要干道、地面铁路、河道、海岸线构成骨架；大/密地块沿真实次级道路细分 | 生成基础 |
| 任务网格 | 聚合完整原子街区，优先连通与可执行性 | 队长分给队员 |
| 团队片区 | 聚合完整任务网格，商户负载为主、面积次要 | 管理员分给团队 |

面积或商户变化优先调整归组，不任意画新直线、切半个原子街区。主要干道地块不能一律视为不可细分，否则天然大块/长条无法优化。

## 边界和聚合规则

- 面分割网络与通行网络分开：先处理bridge/tunnel/layer，再节点化和polygonize；地下线不直接作地面边界，桥梁不填回水面。断头路不强行闭环，缺口和未闭合线要报告。
- 快速路/地面铁路优先保留；主要干道作为骨架和跨越成本，不能仅凭tag推断可步行跨越。初始道路等级候选motorway/trunk/primary/secondary，tertiary由样区决定。
- 保留现有3倍数量上限、100m窄河证据规则、包含归并与零商户独立区域排除审计；任务层仍优先陆地连续。真实水面不计面积，绘图封洞不参与空间计算。
- 优先级：完整覆盖/商户唯一归属与合法边界 → 形状/通行 → 商户负载 → 面积次要成本 → 数量上限。不为凑数超载，不为补负载吞并细长链；冲突明确失败。
- 去长臂用整条叶子街区链转移或相邻片区联合重分；双方连通、形状和负载都检查，不能仅把问题转给邻片。新闭合的包含关系再次整理。
- 用米制旋转外接矩形检查长宽比，并另查长臂、深凹、狭颈；外轮廓形状和真实水洞周长分开。紧凑度4πA/P²与周长比P/(2√(πA))互为变换，避免重复计罚。

## 参数待验证

当前工作区默认面积权重0.15，已有正式#3使用15%，但严格形状规则仍无法满足数量上限。样区可比较0.25/0.15/0.10及“不补低负载”策略，复用主会话已有结果，不重复全量运行。

尚未定案：骨架道路等级、过街代价、步行/骑行/驾车方式、形状阈值、任务目标面积/商户量。首轮沿用现有约1km²（0.5～2km²）作对照，外部方案0.1km²不自动采纳。范围不采用“扣水后只留最大单Polygon”，以免丢失河对岸责任地块；不能未经确认改成全覆盖所有无商户陆地。

## 实施阶段与停止条件

| 阶段 | 工作与交付 | 停止条件 |
|---|---|---|
| A 基线 | 固定当时正式版本、代码/参数/输入指纹、CRS/精度；定位样例，统计全域形状、负载、数量与耗时 | 输入可复现，问题可定位 |
| B 自然地块 | 复用OSM快照，核实道路/铁路/水系及层级；试密集城区、河岸、铁路立交、低密度、内部岛状地块 | 原子面边界可追溯，无未解释重叠/漏地 |
| C 两层聚合 | 同一原子集合生成任务网格和片区，固定排序；比较整链转移、邻片重分与面积权重 | 样例及全域改善，邻区不恶化，商户守恒和数量/水域约束通过 |
| D 最终验收 | 最终候选一次全域审计，报告绑定GeoJSON SHA-256；真实地图检查边界、公式、图层与移动端 | 数据与报告同指纹，相关回归和视觉验收通过 |
| E 版本切换 | 候选通过后再决定持久化/迁移，复用现有服务；备份、核验任务活动、承接归属、事务替换 | 明确切换授权，历史不丢失，可恢复；生产另行发布 |
