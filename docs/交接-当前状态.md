## 6. 风险与注意事项

### 6.1 ⚠️ 别再对生产跑 `bd_sync_prod.py --replace`
用户在**生产界面**上手工配了队员/队长（92 条 member 日志）✗ 一旦 `--replace` 重灌，
`bd_team_member` 会被本地导出（47 行）覆盖，**用户的真实配置全丢**。
以后若只是新增车站/线路：**只同步 `bd_area / bd_line / bd_station_place / bd_station`**，
任务用增量（按 place_id 比对），**永远不要碰 `bd_team*`**。这块建议改造成带
`--only=geo,tasks` 的增量模式（backlog 里的"车站增量同步"）。

### 6.2 生产队长口令我没改过
6 个队长账号我一律没动（`must_change_password=f`、有口令）。用他们平时的口令登录即可。
⚠️ 我**只在 10-06 首次上线时**把当时的 6 个人 `role` 改成 `leader`（其中 ogawa 后来被用户换掉了）。

### 6.3 生产上无法验证队长侧页面
我没有队长口令（也不该改），所以队长相关界面（派工标记、自报表单）**只在本地用同一份代码真浏览器验过**。
若队长反馈异常：先让他**硬刷新**（`Cmd+Shift+R`，可能是缓存），再查 `users.role` 与 `bd_team_member.role`。

### 6.4 静态资源改了不用管缓存，但别删文件
模板写 `?v={{ static_ver('app.css') }}`（文件 mtime+size）→ 生产 nginx 给 `immutable` 一年。
**删了 `app/static/` 里的文件，版本号会算不出来**（回退成 `0`，缓存就乱）。

```bash

./scripts/dev_server.sh                                  # http://127.0.0.1:8000（admin/demo123）
./.venv/bin/python -m pytest tests_web tests -q           # 全量（约 2.5 分钟）

  SELECT version_num FROM alembic_version; SELECT count(*) FROM bd_task;\""
ssh store-prod "docker exec deploy-db-1 psql -U store_settle -d store_settle -At -F'|' -c \"
  SELECT m.team_id, p.display_name, u.username, m.role, u.role FROM bd_team_member m
  JOIN persons p ON p.code=m.person_code LEFT JOIN users u ON u.person_code=m.person_code
  WHERE m.end_date IS NULL ORDER BY m.team_id;\""

# 发布（详见 AGENTS.md §发布流程）
TS=$(date +%Y%m%d_%H%M%S); ssh store-prod "mkdir -p /opt/store-settle/releases/$TS"
rsync -a --delete -e ssh --exclude '.git' --exclude '.venv' --exclude '__pycache__' \
  --exclude '*.pyc' --exclude '*.db' --exclude 'data/' --exclude '.pytest_cache' \
  --exclude '.DS_Store' ./ store-prod:/opt/store-settle/releases/$TS/
ssh store-prod "cp /opt/store-settle/current/deploy/.env /opt/store-settle/releases/$TS/deploy/.env; \
  rm -f /opt/store-settle/current; ln -s /opt/store-settle/releases/$TS /opt/store-settle/current"
ssh store-prod "cd /opt/store-settle/current/deploy && docker compose build web mcp && \
  docker compose up -d --no-deps web mcp"     # ⚠️ mcp 必须一起建

# 回滚
ssh store-prod "rm -f /opt/store-settle/current; ln -s /opt/store-settle/releases/<上一个TS> /opt/store-settle/current; \
  cd /opt/store-settle/current/deploy && docker compose up -d --no-deps web mcp"
```
