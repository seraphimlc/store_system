# 阿里云 OSS 开通清单（员工打卡照片存储用）

> 用途：员工打卡的**门头照片**存到 OSS（服务器本地不落照片）。
> 本文分两部分：**一、内部要点**（我们自己看的）+ **二、客户版操作步骤**（可直接转发给客户）。
> 事实核对时间：2026-09-27；价格为海外地域按量计费的量级估算，最终以阿里云官方价格页为准。

---

## 一、内部要点

### 1. 谁申请、谁持有
- 客户用**自己的阿里云账号**开通（建议企业实名认证账号），Bucket、数据、账单都归客户。
- **凭据必须是 RAM 子账号的 AccessKey，不要用主账号 AK**（主账号 AK 权限等于整个账号，一旦泄漏后果不可控）。
- 我们只在服务器 `deploy/.env` 里配置，**不进代码库、不写进任何文档**。

### 2. 要开通的东西（3 件）
1. **OSS 服务**（按量付费，无最低消费、无月租）；
2. **1 个私有 Bucket**；
3. **1 个 RAM 子账号 + 最小权限策略**（只允许操作该 Bucket 下 `checkins/` 前缀）。

### 3. 规格建议
| 项 | 取值 | 理由 |
|---|---|---|
| Bucket 名称 | `visit-settle-checkin`（全局唯一，被占用就加后缀） | 用途清晰 |
| 地域 | **日本（东京）ap-northeast-1** | 与线上服务器同区域，上传/下载都在日本境内，延迟低 |
| 读写权限 | **私有** | 照片含门店信息，绝不公开可读；取图走我们登录态鉴权路由 |
| 存储类型 | **标准存储** | 低频访问型不适合「随时可能被翻出来核查」的场景 |
| 服务端加密 | 可选（SSE-OSS 即可） | 增加一道保险 |
| CORS | **不需要配置** | 走服务端代理上传，浏览器不直连 OSS |
| 版本控制 / 静态网站 | 都**不开** | 用不上 |

### 4. 费用估算（按 34 人 × 15 家/日 × 22 日 ≈ 11,200 张/月，单张约 300KB）
| 项目 | 计算 | 估算 |
|---|---|---|
| 存储 | 一年约 40GB × $0.017/GB/月 | ≈ **$0.7/月** |
| 上传（公网入流量） | **免费** | $0 |
| 下载（外网流出流量） | 按每月核查浏览约 5GB × $0.08~0.12/GB | ≈ **$0.5/月** |
| API 请求费 | 每月约 2.3 万次 PUT/GET | 可忽略 |
| **合计** | | **每月 1 美元量级（约 ¥10 以内）** |

> 阿里云 OSS 的**上传不收费、只有下载收费**，这是它对本场景特别划算的原因。最终单价以[官方价格页](https://www.aliyun.com/price/product#/oss/detail)所选地域显示为准。

### 5. 保留与清理
- 照片**保留 24 个月**，由我们的脚本按月删除（删对象 + 在库里标记「无图」，记录本身不删）；
- 建议客户在 OSS 侧再配一条**生命周期兜底规则**（例如对象创建 900 天后删除或转归档），防止我们的脚本因故障没跑而无限累积。

### 6. 要客户回给我们的东西
1. **AccessKey ID / AccessKey Secret**（RAM 子账号的）
2. **Bucket 名称** + **Region/Endpoint**（东京为 `oss-ap-northeast-1.aliyuncs.com`）
3. 确认 Bucket 读写权限为「私有」
4. 交付渠道：**不要微信/邮件明文**，用密码管理器或一次性链接

### 7. 我方配置方式（对应环境变量）

| 环境变量 | 值来源 |
|---|---|
| `VISIT_CHECKIN_STORAGE` | `oss`（本地开发用 `local`，**生产只用 `oss`**） |
| `VISIT_OSS_ENDPOINT` | 例 `oss-ap-northeast-1.aliyuncs.com` |
| `VISIT_OSS_BUCKET` | 客户创建的 bucket 名 |
| `VISIT_OSS_AK` / `VISIT_OSS_SK` | RAM 子账号 AccessKey |
| `VISIT_OSS_PREFIX` | 默认 `checkins/` |

配在线上 `deploy/.env`，**不进代码库**；改完重启 web 容器即生效。相关开关：`VISIT_CHECKIN_RETENTION_MONTHS`（默认 24）、`VISIT_CHECKIN_MAX_PHOTOS` / `VISIT_CHECKIN_MAX_PHOTO_MB`（默认 5 / 5）。

## 二、客户版操作步骤（可直接转发给客户）

### 0. 事前确认

- 账号、Bucket、数据、账单**都以贵司名义**创建（我方不承担费用）。
- 交付给我方的凭据，**必须使用「RAM 用户（子账号）」的 AccessKey**。**请勿使用主账号 AccessKey**（权限过大，一旦泄漏影响范围不可控）。
- 照片**不会保存在我方服务器的本地磁盘**，全部存放在 OSS。

### 1. 开通 OSS 服务

1. 登录 https://www.aliyun.com/ 。
2. 进入控制台 →「对象存储 OSS」。
3. 首次使用请先**开通服务**（按量付费、无最低消费）。

### 2. 创建 Bucket

在「创建 Bucket」中按下列配置创建：

| 项目 | 设置值 |
|---|---|
| Bucket 名称 | `visit-settle-checkin`（全局唯一；若已被占用，请在末尾加数字等） |
| 地域（Region） | **日本（东京）ap-northeast-1** |
| 存储类型 | **标准存储** |
| 读写权限（ACL） | **私有（Private）** |
| 服务端加密 | 任意（建议 SSE-OSS） |
| 版本控制 / 静态网站托管 | 不使用（保持关闭） |
| CORS 设置 | **不需要**（上传经由我方服务器，浏览器不直接访问 OSS） |

> **读写权限请务必设为「私有」**。照片包含门店信息，不能公开。照片的查看只能经由我方系统的登录鉴权进行。

### 3. 创建 RAM 用户（子账号）

1. 控制台 →「RAM 访问控制」→「用户」→「创建用户」。
2. 输入登录名，**只勾选「编程访问」**（不需要控制台登录）。
3. 创建后出现的 **AccessKey ID / AccessKey Secret 请记录下来**（Secret 之后无法再次显示）。

### 4. 授予最小权限策略

「权限策略」→「创建策略」→「脚本编辑」，粘贴以下内容创建策略，并授权给上述用户：

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "oss:PutObject",
        "oss:GetObject",
        "oss:DeleteObject",
        "oss:AbortMultipartUpload",
        "oss:ListParts"
      ],
      "Resource": [
        "acs:oss:*:*:visit-settle-checkin/checkins/*"
      ]
    },
    {
      "Effect": "Allow",
      "Action": ["oss:ListObjects"],
      "Resource": ["acs:oss:*:*:visit-settle-checkin"],
      "Condition": {"StringLike": {"oss:Prefix": ["checkins/*"]}}
    }
  ]
}
```

> 上述策略的含义是「只能读写该 Bucket 下 `checkins/` 目录」。若 Bucket 名称有改动，请同步修改 `Resource` 中的名称。
> **不要**授予 `AliyunOSSFullAccess`（OSS 全量权限）。

### 5. 生命周期规则（可选、建议）

在「Bucket」→「生命周期」中建议添加：

- 前缀：`checkins/`
- 操作：对象创建后 **900 天** 删除（或转为归档）

> 我方也会以 **24 个月**为期限删除照片。这一条是作为**保险**（防止我方脚本故障导致无限累积）。

### 6. 费用概算

按预计用量（34 名员工 × 每日 15 件 × 每月 22 天 ≈ 11,200 张/月，单张约 300KB）：

| 项目 | 概算 |
|---|---|
| 存储（一年约 40GB） | 约 0.7 美元/月 |
| 上传（公网入流量） | **免费** |
| 下载（外网流出流量，按每月 5GB 估算） | 约 0.5 美元/月 |
| API 请求 | 极少（可忽略） |
| **合计** | **约 1 美元/月（10 元以内）** |

> OSS 是**上传免费、只有下载计费**的计费方式，因此本用途成本极低。准确单价请查看[阿里云官方价格页](https://www.aliyun.com/price/product#/oss/detail)对应地域。

### 7. 需要回给我方的信息

1. RAM 用户的 **AccessKey ID / AccessKey Secret**
2. **Bucket 名称**与**地域 / Endpoint**（东京为 `oss-ap-northeast-1.aliyuncs.com`）
3. 确认 Bucket 读写权限为「私有」

> **凭据请通过安全渠道交付**：请勿在聊天工具或邮件中明文粘贴，建议使用密码管理器的共享功能或带有效期的共享链接。我方只会写入服务器环境变量，不会保存到源码或代码仓库。

### 8. 常见故障

| 现象 | 原因与处理 |
|---|---|
| Bucket 名称创建失败 | 名称全球唯一，已被占用。请追加数字或公司名 |
| 上传报 `AccessDenied` | RAM 策略的 `Resource` 中 Bucket 名称与实际不一致 |
| 报 `NoSuchBucket` | 地域（Endpoint）指定错误。东京地域应为 `oss-ap-northeast-1.aliyuncs.com` |
| 照片可被外部访问 | 检查 Bucket ACL 是否被设为「公共读」（必须为私有） |
| AccessKey Secret 丢失 | 无法再次显示。请为该 RAM 用户新建 AccessKey 并交付我方（我方替换环境变量） |
