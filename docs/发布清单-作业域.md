⚠️ 已知风险点：`d3e4f5a6b7c8`（作业域地基）里 `sa.Text(server_default=sa.text("('')"))`
是**按 MySQL 语法写的**；PG 上 `TEXT DEFAULT ('')` 合法，但干跑时要确认没有语法错。
真出错就按报错改迁移再跑（线上还没数据，改迁移是安全的）。

## 4. 部署（按 AGENTS.md 的发布流程）

```bash

  rm -f /opt/store-settle/current; ln -s /opt/store-settle/releases/$TS /opt/store-settle/current"

```

## 7. 回滚

1. 应用：`ln -sfn /opt/store-settle/releases/<上一个 TS> /opt/store-settle/current` + 重启 web
2. 数据：作业域表**首次发布会新建**，回滚应用不影响数据；若已灌数据要回退：
   `gunzip -c /opt/store-settle/backup_ops_<TS>.sql.gz | docker exec -i deploy-db-1 psql -U store_settle -d store_settle`
3. 迁移：`bd_*` 迁移都带 `downgrade()`；真要退用 `alembic downgrade <rev>`
   （但**表里有数据时慎用**）
